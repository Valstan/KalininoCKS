# Визуальный образ «Калинино ЦКС» — как это устроено

Документ для переноса образа в раздел «Калининский СДК» портала культура.вмалмыже.рф (D-074). Источник истины — `web/src/app/(frontend)/globals.css` (503 строки, один файл), разметка шапки и подвала — `components/SiteChrome.tsx`, главная — `_views/HomeView.tsx`. Введён PR #16, подвал доработан PR #22, кнопка каталога — PR #20.

## Идея

Сельский дом культуры как праздничная сцена: **льняное полотно** фоном, **вышивка и лоскут** в рамках карточек, **гирлянда флажков** в подвале, **лубочные** тени-подложки в два цвета. Три опорных цвета — красный, синий, медовый — как в северной вышивке и на расписных наличниках. Плоские жёсткие тени вместо размытых, скошенные неравные радиусы вместо симметричных, лёгкие повороты элементов на 1–2°: «сделано руками», а не выровнено по сетке.

## Токены

```css
:root {
  --ink: #3b261b;        /* текст, обводки, «чернила» */
  --muted: #756052;      /* второстепенный текст */
  --linen: #f6ebd5;      /* фон страницы — лён */
  --paper: #fffaf0;      /* фон карточек и панелей */
  --cream: #fff4d4;      /* светлый текст на цветном, орнаментальные знаки */
  --red: #c9341f;  --red-dark: #8f2419;
  --blue: #14508a; --blue-dark: #0b355f;
  --honey: #efa928; --gold: #ffc84a;
  --grass: #647b3c;      /* акцент, почти не используется */
  --max-width: 1180px;
  --space: clamp(1rem, 4vw, 2rem);
  --shadow: 0 20px 50px rgba(70, 40, 18, 0.16);
}
```

## Шрифты

Google Fonts, один `@import`: **Kurale** (заголовки h1–h3, название в шапке — кириллический гротеск с рукописным характером, `font-weight: 400`), **Montserrat** 500–900 (текст и UI, много `800/900` для кнопок и подписей капслоком с трекингом 0.08–0.16em), **Marck Script** (только одна строка в подвале — «eyebrow» курсивом 2.3rem золотом).

## Фон: лён

`body` — `--linen` плюс четыре слоя: две тонкие сетки 5px (вертикальная и горизонтальная линии `rgba(113,69,34,.035/.025)`) дают переплетение нитей, два мягких радиальных пятна (`#fff9e9`, `#efd8ac`) — неравномерность окраски. Поверх `body::before` фиксированный слой с `repeating-linear-gradient(92deg, …, #7c4d2b 12px 13px)` при `opacity .18` и `mix-blend-mode: multiply` — косые «нити». Панели (`.linen-panel`, статьи, ленты) повторяют приём на `--paper` одной вертикальной сеткой 7px.

## Орнаментальные знаки

Символы Unicode вместо картинок: `❋` (цветок-восьмилистник), `✦` (звезда), `◆`. Ими набраны: полоса под шапкой (`.site-header::after`, `◆ ❋ ◆ ❋ …` кремовым с трекингом 0.65rem), маркеры пунктов меню и кнопок (`::before`), «стежки» на герое, полупрозрачный узор по углам героя и карточек (`#fff1`, 4–8rem). Печати на углах панелей: `.linen-panel::before/::after` — квадрат 58px с `❋`, красный слева-сверху, синий справа-снизу, повёрнут на ±12°, радиус `16px 8px 16px 8px`.

## Рамки и тени (главный узнаваемый приём)

- Панель: `border: 5px solid var(--ink); border-radius: 26px 62px 28px 72px; box-shadow: 10px 12px 0 var(--honey), 16px 20px 0 var(--red)` — две смещённые плоские подложки, медовая и красная.
- Герой: рамка 7px, радиус `32px 95px 36px 76px`, тени `14px 16px 0 red, 23px 27px 0 honey` + мягкая `--shadow`; внутри пунктирная рамка `::before` (`3px dashed rgba(255,244,212,.58)`, inset 16px) — «строчка».
- Кнопки: `border: 3px solid ink; border-radius: 10px 22px 10px 22px; box-shadow: 5px 6px 0 ink`; при hover сдвиг на `translate(3px,3px)` и тень укорачивается до `2px 3px` — кнопка «вжимается». Primary — `--gold`, secondary — `--cream`, перед текстом `❋`.
- Меню: синие плашки `border-radius: 9px 9px 18px 18px`, `box-shadow: inset 0 0 0 3px #ffffff1f, 4px 5px 0 honey`, при hover красная с поворотом на −1°. Ссылка наружу (каталог «Сервисы Малмыжа») — медовая с `⌂` и `↗`, чтобы не путать с разделами.
- Мобильные (`≤ 760px`): рамка 4px, тени уменьшены до `7px 8px / 11px 13px`.

## Шапка

Сверху **приветственная лента** `.welcome-ribbon`: тёмно-красная (`--red-dark`) с золотой нижней каймой 3px, повторяющиеся полупрозрачные засечки (`linear-gradient(90deg, … #ffffff24 12px 15px …) / 28px 100%`), текст капслоком 0.76rem/800 с `✦` по краям: «Калинино — здесь праздник собирает своих». Ниже шапка на `rgba(255,250,240,.96)` с тройной нижней кромкой: `border-bottom: 8px solid blue; box-shadow: 0 6px 0 honey, 0 11px 0 red`. Эмблема 100×100 (`/brand/kalinino-emblem.webp`, drop-shadow, при hover поворот −3° и увеличение 1.04). Название — Kurale `clamp(1.15rem, 2vw, 1.55rem)`, над ним красная подпись капслоком 0.64rem.

## Герой главной

Двухколоночная сетка `1.04fr 0.96fr`, min-height 610px, синий градиент `135deg, blue-dark → blue 56% → #23669d` с вертикальной сеткой 12px. Заголовок кремовый `#fff7df` с жёсткой тенью `3px 4px 0 red-dark`. Eyebrow-плашка золотая с чёрной рамкой, повёрнута на −2°. Справа — эмблема (до 650px, поворот 2°, анимация `gentle-sway` 6s), за ней **«солнце»** — круг из точек `border: 34px dotted rgba(255,200,74,.45)`, вращается 70s, и два «стежка» `✦ ❋` золотом с красной тенью.

## Карточки традиций

Три карточки `.traditions-grid` (красная, синяя, медовая), средняя повёрнута на 1.2° и опущена на 16px; крупный полупрозрачный `✦` в углу; эмодзи-знак 3rem с тенью `3px 3px 0 ink`.

## Подвал

Тёмный на `--ink` с вертикальной сеткой 11px, верхняя кромка `12px solid red` + `inset 0 8px 0 honey`. Над ним **гирлянда** `/brand/folk-garland.webp` (`.site-footer__garland`: absolute, `top: -125px`, ширина `min(1400px, 116vw)`, drop-shadow) — поэтому у подвала `padding-top: 8.5rem` и `overflow: hidden`. Текстовая колонка лежит на плашке `rgba(40,24,15,.78)` с медовой каймой (PR #22: без неё текст тонул в узоре гирлянды). Ссылки золотые, eyebrow — Marck Script.

## Что переносить в раздел портала

Минимум, по которому раздел узнаётся как «Калинино»: палитра (три опорных цвета плюс лён/бумага), лента с фразой, эмблема, двойная плоская тень с неравными радиусами на карточках, гирлянда над подвалом раздела. Шрифты и знаки-орнаменты — по возможности; фон-лён — если не спорит с общим фоном портала.
