- **🔴 Две собственные починки оказались неверными; поймала их состязательная вычитка диффа перед отправкой.**
  - **`env:` не защищает.** Вынести значение из `${{ }}` в блок `env:` шага мало: раннер печатает **сам блок `env:` с раскрытыми значениями**, маскируя только `secrets`. Проверено на нашем логе (деплой 22.08, шаг Setup SSH): `SSH_PRIVATE_KEY: ***`, а рядом хостнейм и SSH-порт открытым текстом. → `DEPLOY_SSH_HOST`, `DEPLOY_SSH_USER`, `APP_PORT`, `PROD_ENV_FILE` переведены в **`secrets`**, одноимённые `vars` удалены. `DEPLOY_SSH_PORT` осознанно оставлен в `vars`: 22 универсален, а маскировка такой короткой строки замазала бы все даты в логе.
  - **Редактор журнала не ловил хостнейм.** `journalctl` по умолчанию печатает «дата ХОСТНЕЙМ юнит[pid]: текст» — имя машины в каждой из 80 строк; мой `sed` его не трогал. Проверял фильтр на том, что собирался фильтровать, а не на реальном формате вывода. → `-o cat` у `journalctl`, `-n 0` у `systemctl status`, `sed` остался вторым рубежом.
  - Обе ошибки одного вида: **проверка починки на модели вместо артефакта.**
- **Реквизиты в `secrets`:** `DEPLOY_SSH_HOST`, `DEPLOY_SSH_USER`, `APP_PORT`, `PROD_ENV_FILE`. В `vars` осталось только публичное: `NEXT_PUBLIC_SERVER_URL` (адрес витрины) и `DEPLOY_SSH_PORT`. Корень деплоя — `$HOME/kalinino`, раскрывается на самой машине; чтобы развязка не стала тихой, деплой перед рестартом сверяет `WorkingDirectory` юнита с разложенным релизом и падает при расхождении (иначе поднялся бы старый код, а smoke-check покрасил бы прогон зелёным). Дев-дефолты порта переведены на нейтральный 3000.
- **Попутно укреплён `apply-migration.yml`:** пустой `DATABASE_URI` больше не проходит молча (пайплайн возвращал успех от `sed`, а libpq ушёл бы на локальный сокет и БД по имени пользователя), `psql` в preflight вынесен из `echo "$(…)"` — иначе его код возврата терялся; имя миграции приезжает через `env:` и проверяется по форме.
- **Побочно закрыт silent-failure:** фолбэк `NEXT_PUBLIC_SERVER_URL` на loopback убран — такая сборка уехала бы на прод молча-битой; теперь отдельный шаг падает с `::error::`.
- **Осознанный остаток — 7 позиций в двух systemd-юнитах** (`deploy/kalinino.service`, `deploy/kalinino-vk-sync.service`): имя системного пользователя, рабочий каталог, путь env-файла, зависимость от локального `postgresql.service`, лимит памяти. Убрать без правки самой площадки нельзя: юнит копируется на сервер как есть, плейсхолдер разошёлся бы с установленным. Настоящее лечение — выделенный сервисный пользователь и корень вида `/opt/...`, но это смена раскладки прода, а владелец решил площадку не трогать.
- **Правило поймало ошибку через минуту после написания:** `gh variable set … --body /etc/…` записал `C:/Program Files/Git/etc/…` — Git Bash переписывает аргумент, похожий на unix-путь (MSYS path conversion). Это **пятый слой** к четырём, названным Мозгом, и он не про экранирование: символа-триггера в строке нет вообще. Дописано в канон и в письмо.
