## Сделано (продолжение сессии 2026-08-22)

- **Graceful shutdown (PR #27).** Разобрались с последним открытым пунктом Мозга и нашли, что **наше же утреннее письмо было неверно**: обработчик SIGTERM у Next есть (`start-server.js:356-359`). Настоящая грабля тоньше: `closeAllConnections()` стоит под `if (isDev)`, поэтому сокет, дописавший ответ уже ПОСЛЕ начала остановки, держит `server.close()`. Замер на боксе (Node 20): **29 089 мс без обёртки против 2149 мс с ней**, тело ответа доезжает в обоих случаях. Значит выставленный утром `KEEP_ALIVE_TIMEOUT=65000` **сам по себе удлинял простой**. Обёртка `deploy/server-graceful.mjs` (перехват `http.createServer`, FIN по завершении ответа, форс-выход, `headersTimeout`), `ExecStart` переключён, `TimeoutStopSec=30`. На проде рестарт при висящем keep-alive — **57 мс**. Поправка Мозгу отправлена (PR #28): выход не 143, а 0; «обёртка ради нуля» верно только для idle-сокета.
- **🔴 Живой VK-токен в публичном репозитории Гоньбы** (PR #26). Найден при чтении соседей как образцов: `Valstan/Gonba/seed-vk-source.sql`, файл в индексе git, отдаётся GitHub API, репозиторий публичный с 17.08.
