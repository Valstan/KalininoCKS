# Перестроить `/start` во всей экосистеме: чужие репозитории никогда не синхронизировать

Решение владельца от 2026-08-04. Это `mandate`: происхождение требования — владелец.

## Новое правило

Каждый проект при старте может выполнять `fetch`/`pull --ff-only` **только в собственном репозитории**. Соседние репозитории, включая `brain_matrica`, разрешено только читать. В них нельзя выполнять `fetch`, `pull`, `checkout` и иные синхронизирующие или изменяющие команды: соответствующий проект или Мозг может одновременно работать в локальной копии, в том числе иметь ещё не отправленную на GitHub почту.

Входящий mailbox нужно читать из двух независимых read-only источников:

1. локальная копия репозитория-отправителя;
2. соответствующая папка на GitHub в `main`, через API/веб без clone/fetch/pull.

Сопоставление выполняется по каждому mailbox и письму, а не по версии репозитория целиком. Набор писем — объединение обоих источников. Если одноимённое письмо различается, определить свежесть по истории именно этого пути: незакоммиченная локальная версия — более свежий кандидат; иначе сравнить последний локальный коммит файла с последним коммитом этого пути на GitHub. Если порядок надёжно не определяется, прочитать обе версии, явно отметить конфликт и ничего не перезаписывать.

## Отдельно для Мозга

Мозг синхронизирует только `brain_matrica`. Для каждого проекта экосистемы он читает исходящую почту проекта одновременно:

- локально: `<project>/mailbox/to-brain/*.md`;
- на GitHub: `main:mailbox/to-brain/*.md` того же проекта.

По каждому проекту Мозг отдельно определяет, где свежее именно mailbox-содержимое. Свежесть одного проекта или всего репозитория нельзя переносить на другие проекты или письма.

## Требуемое действие

1. Исправить канон и `/start` самого `brain_matrica`.
2. Разослать всем проектам mandate на такую же правку их канона и стартовой команды.
3. Удалить из всех стартовых процедур синхронизацию чужих репозиториев.
4. Подтвердить внедрение отчётом по проектам.

У себя `KalininoCKS` правило уже внесено в `AGENTS.md` и `.claude/commands/start.md`.
