Имя job'а: **`gates`**, workflow `CI` (`.github/workflows/ci.yml`), `on: pull_request` + `workflow_dispatch`. Делай обязательным.

Внутри: gitleaks по всей истории → `pnpm lint` → `typecheck` → `build` против эфемерного Postgres 17. Основа — `ci.yml` ДК (тот же стек), шаг секретов — у Казанской.

Фильтров по путям нет намеренно — по твоей же причине: `paths:`-проверка, сделанная обязательной, подвесит навсегда PR, который этих путей не трогает.

## 2. Сканер секретов — **сделано, и он сразу нашёл настоящее**

Тем же PR, поэтому очередь «важнее сканера» не понадобилась.

Первый прогон — 65 срабатываний, **все в одном файле**: `scripts/.work/wall.json` — сырой ответ VK API на 1 МБ, закоммиченный по недосмотру в PR #12 ещё 04.08 и с 17.08 лежавший в **публичном** репозитории. Внутри не наши учётные данные, а `access_key`/`web_view_token` медиа-объектов публичной стены сообщества.

Сделано: каталог снят с учёта и внесён в `.gitignore`; в истории файл остаётся — переписывать её нельзя (`main` защищён, force-push запрещён), поэтому в `.gitleaks.toml` стоит задокументированное исключение именно этого пути.

**Переносимое, если сочтёшь нужным внести в библиотеку:** сканер секретов на контент-сайте ловит не ключи, а **рабочие дампы выгрузок** — `.work/`, `.cache/`, `tmp/` рядом со скриптами импорта. У всех, кто тянет контент из ВК/1С/соцсетей, такой каталог есть, и он попадает в коммит вместе с фичей импорта. Проверяется одной командой на любом репо портфеля:

```bash
git ls-files | grep -E '\.(work|cache|tmp)/|/tmp/'
```

## 5. Два `recommend` от 08.08

**Рефлекс #014 — сделано.** В `AGENTS.md` появился раздел «📚 Библиотека Мозга»: греп `GOTCHAS.md` по симптому до собственного расследования, с примерами находок нашего стека. PR [#23](https://github.com/Valstan/KalininoCKS/pull/23).

**Keep-alive / SIGTERM — сделано наполовину, вторая половина отложена с датой.** Проверял фактическое состояние на боксе, а не строки в репозитории, как ты и просил:

- `KEEP_ALIVE_TIMEOUT` **не был задан** → выставлен **65000** в `/etc/kalinino/kalinino.env`, сервис перезапущен, `/` отвечает 200. Полезная деталь для рассылки соседям: **Next standalone `server.js` читает именно эту env-переменную**, флага запуска у него нет — то есть у всех сайтов на standalone пункт закрывается одной строкой в env, без пересборки и без правки кода.
- nginx у нас проксирует без `upstream { keepalive N }`, поэтому keep-alive к бэкенду сейчас не используется и гонка не воспроизводится. Таймаут поставлен на будущее — конвейер Сарафана (D-015) шлёт посты сериями, это ровно тот профиль.
- **Обработчика `SIGTERM` нет** — в бандле standalone его нет вовсе, нужна собственная обёртка над `server.js` в шаге сборки CI. **Отложено до 2026-09-30.** Триггер вернуться раньше: первый же 502 при серийном ingest или жалоба на пропавшие посты после деплоя. Риск сейчас — рвущиеся запросы в момент рестарта при выкате, то есть секунды раз в деплой.
