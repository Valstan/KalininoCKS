# Гейты #104: ревизия сделана

**Сколько гейтов:** 6 (lint, typecheck, deadcode/knip, Migration guard, build, smoke-check). Тесты, semgrep, gitleaks и branch-protection — **отсутствуют как класс** (нет фреймворка/скрипта, нет плагинов в CI, API protection на free-плане 403).

**С подтверждённым красным прогоном:** 4 из 6 — lint (нарушение error-правила `no-sync-scripts` → exit 1), typecheck (TS2322 → exit 2), knip (3 неиспользуемых файла → exit 1), Migration guard (фейковая миграция → exit 1, та же bash-логика, что в CI). У build и smoke-check красных прогонов нет и не устраивались намеренно: это деплой-цепочка, красный прогон = сломанный прод; до этого они 4/4 зелёные.

**Что нашлось (главное, класс #104):**
1. **`deploy-prod.yml` не запускает lint, typecheck и тесты вообще.** CI-контур: migration guard → install → generate → build → smoke. Lint/typecheck/deadcode живут только как локальные скрипты package.json, завязанные на «честное слово» агента из AGENTS.md; GitHub ничего не проверит, если шаг пропустить. PR-проверок обязательных нет (free-план).
2. **Lint частично слепой:** все пользовательские правила — `warn` (включая `no-explicit-any`, `no-unused-vars`), гейт валится только на error-правила пресетов. Плюс 4 постоянных warn в сгенерированных миграциях шумят в каждом выводе.
3. **knip дефолтный репортер крэшнулся (exit 134, SIGABRT) на прогоне с нарушениями**, json-репортер отработал корректно (exit 1) — наблюдение на проверку при следующем касании, возможно флейк Windows.
4. `no-img-element` и `no-html-link-for-pages` в `@next/eslint-plugin-next@15.4.11` — `warn` (недавно понижены с `error`), т.е. «зелёный» lint не ловит `<img>` без next/image.

**Решение по плану #104 п.5:** включать новые правила (react-hooks `exhaustive-deps`, кастомные — `error`) НЕ стал: проект тихий by design, контента нет, правила почти наверняка вскроют ворох нарушений в шаблонном коде. Сделаем отдельной веткой, когда будет содержательная задача. Предложение: перенести lint/typecheck в CI (добавить шаг в deploy-prod.yml или отдельный check-воркфлоу) — это 10 минут, но решает главную дыру; жду вашего слова, так как это меняет деплой-контур.
