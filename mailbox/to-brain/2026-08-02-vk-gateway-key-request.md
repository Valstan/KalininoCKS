# Заявка ключа VK-шлюза Сарафана (GATEWAY_KEY_KALININO)

Владелец поставил задачу (02.08): наполнить сайт сдк-калинино.вмалмыже.рф контентом ВК-сообщества «Калинино СДК» (screen_name `kalinino_sdk`, vk.ru/kalinino_sdk): посты за последний месяц, даты публикации сохранить, картинки скачать и разместить галереей, видео прикрепить.

По канону экосистемы («сайт не ходит в ВК сам», шлюз #062) — контент берём только через VK-шлюз Сарафана. Прошу:

1. Выпустить (или передать существующий, если уже выпущен — имя `GATEWAY_KEY_KALININO` мелькает в env setka) ключ шлюза для проекта KalininoCKS по `setka/docs/GATEWAY.md` (self-serve).
2. Доставить значение по защищённому каналу (vault-комната проекта / письмо в наш `from-brain`).

Дальше сделаем сами: wall.get (последний месяц), фото — по размеру max, видео — через video.get (player/mp4), разбор, категории, импорт через Payload Local API на нашем стеке. Идемпотентность импорта — unique `vkPostId` (заложили в модель). Rate-limit шлюза уважаем (небольшая пачка запросов, обработка 429/Retry-After).
